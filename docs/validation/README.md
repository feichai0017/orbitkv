# Development validation archive

Historical correctness, compiler, provider, startup and state-lifecycle records
live here. They establish only the behavior and source identities stated in
each record; their diagnostic timings are not model serving performance.

JSON records are unchanged. Paths and source identities inside them describe
their original runs. Markdown links follow the new archive location, and
README checksum entries reflect those link edits. Original files remain in
Git history.

New development runs belong under ignored `.qualification/`. Describe lasting
contracts and optimization findings in the relevant development document;
do not publish a new result package for every refactor or test run.

Public model inference measurements belong in [results](../../results/README.md).
