# H20 Dense SGLang Binding

OrbitKV restored a 4K logical pure-SWA Prefix as its compiler-proven 1K live
tail, bound SGLang page IDs into the generated Dense Runtime, pinned an
immutable view through a real CUDA event, and recycled all 65 resident blocks
through retirement certificates. The one-token continuation matched the
full-capacity kernel-reference output digest.

The Dense path used 3,168 physical token slots versus 32,768 for the reference
allocator, a 90.33% reduction for this workload. This is a single-request,
one-continuation-token qualification. Multi-token decode, overlap, Radix,
speculation, disaggregation, CUDA Graph, and Hybrid Full+SWA Dense binding are
not qualified and fail closed where applicable. The recorded timing is not a
performance-win claim.
