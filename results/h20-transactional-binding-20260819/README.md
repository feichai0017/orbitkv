# H20 Transactional Binding

OrbitKV prepared an invisible Rust binding intent for GPT-OSS 20B, loaded the
Full and SWA Capsule components into SGLang, committed the complete physical
receipt, and only then published the hydrated prefix to admission.

The trace records `binding_prepared -> binding_committed -> capsule_hydrated`.
Rust derived Full `[0,1024)` and SWA `[896,1024)` from the compiled Retention
plan. This is a correctness and wiring result, not a new performance claim.
