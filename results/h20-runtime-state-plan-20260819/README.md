# H20 Unified Runtime StatePlan

One fingerprinted `runtime-state-plan.json` drove GPT-OSS 20B retention,
layout, SGLang policy, FFI owner mode, and Capsule limits. The adapter used only
`ORBITKV_RUNTIME_STATE_PLAN` as its semantic contract; store, model identity,
and shared-library paths remained external deployment resources.

The real H20 smoke hydrated 1,024 cached tokens with the same output digest as
the previously qualified Hybrid Capsule path. This is an artifact-wiring and
identity result, not a new latency claim.
