# OrbitKV contributor guide

Use [AGENTS.md](AGENTS.md) for repository layout, current build/test gates,
code style, and commit conventions. The earlier copy of those instructions in
this file was stale and described removed inference gRPC and an obsolete
SGLang adapter.

For product boundaries and deployment status, use
[architecture](docs/architecture.md), [roadmap](docs/roadmap.md), and
[P/D versus NIXL](docs/pd.md). Do not describe future recovery contracts,
distributed catalog, or KV-aware routing as implemented.
